Опиcание работы DNS

DNS (система доменных имён) — система, позволяющая получать информацию о доменных именах, в том числе для их преобразования в IP-адреса.

NS-сервер (сервер имен) — DNS-сервер, который хранит и предоставляет информацию о доменной зоне. NS-запись указывает, какие серверы являются авторитетными для конкретной доменной зоны.

Делегирование домена — передача ответственности за DNS-зону домена определённым авторитетным DNS-серверам. При делегировании домена происходит передача контроля над частью доменной зоны.

A-запись — тип записи адреса в DNS. Связывает имя хоста с IPv4-адресом.

MX-запись — тип DNS-записи для маршрутизации электронной почты. Определяет, какие почтовые серверы принимают электронную почту для домена. Используется с протоколом SMTP.
